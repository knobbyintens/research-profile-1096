# Latent Drift Calibration for Streaming Classifiers

Reference code for the paper "Latent Drift Calibration for Streaming Classifiers" (B. Jones et al.).

## Repository Status

**Released.** This folder is the public implementation accompanying the paper.
The model code lives in `src/`, reproduction scripts in `experiments/`, and evaluation
utilities in `tests/`.

## Usage

See `experiments/config.yaml` for the reference configuration.
